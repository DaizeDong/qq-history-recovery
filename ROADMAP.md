# Roadmap

- Wire the contact mapping from `tools/qqnt_contacts.py` into the decoder output, so records carry names and not just uids.
- HTML output beside JSON, with images and voice, like the sister discord tool.
- Classic Msg3.0.db support when a classic client is available, using its own key route.
- Richer QQNT element types beyond plain text: quotes as structured context, forwarded records, ark cards.
- A single orchestrator that detects which store is present and runs the right pipeline.
